# amspiritllc-website
Official website of AMSpirit LLC

Buildless HTML/CSS on GitHub Pages. No runtime dependencies, external fonts, trackers or analytics. Serve the repository root with a static HTTP server for local preview. `CNAME` remains unchanged.

Original wordmark, icons, hero and social artwork live in `assets/`. Typography uses system fonts. PNG favicon/social files are rendered from the matching SVG sources; no stock imagery or third-party font license is needed.

Changes are reviewed in draft pull requests. Publishing happens only through an owner-approved merge to the Pages source branch. The invoice tool is a separate change; its implementation is not duplicated in the redesign branch. Vendors receive the invoice page URL directly; public pages must not link to it.
